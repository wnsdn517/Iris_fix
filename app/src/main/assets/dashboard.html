사용법

채팅 탭

  • Iris가 수신한 최근 메시지를 채팅방별로 정리해서 보여줍니다.
  • 좌측 목록에서 채팅방을 클릭하면 해당 방의 메시지가 오른쪽에 표시됩니다.
  • 파란 버블: 봇이 보낸 메시지 / 회색 버블: 다른 사람 메시지
  • ID 복사 버튼으로 room ID를 클립보드에 복사할 수 있습니다.
  • 방 이름은 앱이 새 메시지를 수신해야 표시됩니다. 첫 실행 시 chat_id만 보일 수 있습니다.

Shell 명령어

  • POST /exec 엔드포인트를 통해 기기에서 쉘 명령어를 실행합니다.
  • 파일 확인: ls /sdcard/iris_tmp
  • MediaStore 쿼리: content query --uri content://media/external/audio/media --where "_data='/sdcard/iris_tmp/test.mp3'" --projection _id
  • 프로세스 확인: ps | grep kakao
  • 30초 타임아웃. 백그라운드 실행은 지원하지 않습니다.

메시지 전송 테스트

  • text: 일반 문자 메시지. data에 내용 입력
  • image: Base64 인코딩된 이미지 1장
  • image_multiple: Base64 배열 ["data1","data2"]
  • file: 기기 내 파일 경로. 예: /sdcard/iris_tmp/audio.mp3
  • 음성메시지 테스트: type=file, data=.mp3 절대경로

통계

  • 파라미터 없음: 방별 메시지 수 + 봇 시간대별 활동
  • Room ID만: 해당 방의 유저별 메시지 수
  • User ID만: 해당 유저의 시간대별 활동
  • 둘 다: 해당 유저의 해당 방에서 시간대별 활동
  • Room ID는 채팅 탭에서 ID 복사 버튼으로 가져오세요.

AOT Token

  • KakaoTalk 인증에 사용되는 토큰입니다.
  • 도구 탭 → Load Token 버튼으로 불러옵니다.
  • 복사 후 외부 API 호출 시 사용할 수 있습니다.

API 엔드포인트 요약

  • POST /reply — 메시지 전송
  • POST /exec — 쉘 명령어 실행
  • GET /stats?roomId=&userId= — 통계 조회
  • POST /query — SQLite 직접 쿼리
  • GET /aot — 인증 토큰 조회
  • GET /config — 설정 조회
  • WS /ws — 실시간 메시지 수신
